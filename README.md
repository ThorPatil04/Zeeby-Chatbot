## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/yourusername/zeeby-chatbot.git
cd zeeby-chatbot
```

### 2️⃣ Install Dependencies

If using Python:

```bash
pip install -r requirements.txt
```

If using Node.js:

```bash
npm install
```

### 3️⃣ Run the Project

Python:

```bash
python app.py
```

Node.js:

```bash
npm start
```
